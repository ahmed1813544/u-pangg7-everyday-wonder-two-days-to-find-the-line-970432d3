## The entry

One sentence, 101 characters, about a small moment of wonder in everyday life:

> The shadow of a bird crossed the page I was reading, and for a second the sentence flew away with it.

## How it works

`main.py` (stdlib only, deterministic) writes that single sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when unset.

```sh
python3 main.py
```
